# EasyKey — площадка объявлений мастеров по замкам

Веб-приложение для поиска проверенных мастеров по аварийному вскрытию, установке и ремонту замков. Мастера публикуют объявления с контактными телефонами, а клиенты могут быстро найти специалиста рядом с собой и связаться с ним.

## 🛠 Стек технологий
* **Frontend:** React (Vite)
* **Backend:** Node.js, Express
* **Database & ORM:** PostgreSQL, Prisma

## 📌 Статус проекта
* **Этап:** Проектирование и архитектура (MVP)
* **Подробная документация:** [Архитектура проекта (docs/architecture.md)](docs/architecture.md)

## 👥 Роли в системе
* **Гость:** Просмотр каталога, фильтрация по городам и категориям, просмотр детальной информации и контактов мастеров.
* **Пользователь (Мастер / Клиент):** Регистрация/вход, создание и управление своими объявлениями (с прохождением модерации), написание отзывов с защитой от накрутки.
* **Администратор:** Модерация объявлений (одобрение/отклонение с указанием причины), управление пользователями (блокировка нарушителей), перевод записей в статус блокировки для сохранения истории.
